# Конвертация фотографий в WebP

Скрипт `convert_photos.py` рекурсивно обрабатывает изображения из указанной папки и сохраняет их в формате WebP размером 800 × 800 пикселей. Пропорции исходного изображения сохраняются: свободное место заполняется выбранным фоном. Ориентация из EXIF учитывается.

## Требования и установка

- Python 3.13 или новее
- Pillow 13.x

Если установлен Poetry, выполните в папке проекта:

```bash
poetry install
```

Либо установите зависимость напрямую:

```bash
pip install "Pillow>=13,<14"
```

## Запуск

```bash
python convert_photos.py <папка_с_фото> <папка_результатов> [--background auto|white|black|transparent]
```

При установке через Poetry используйте `poetry run python` вместо `python`.

Например:

```bash
python convert_photos.py ./photos ./converted --background white
```

Параметр `--background` задаёт цвет полей вокруг фотографии:

| Значение | Результат |
| --- | --- |
| `auto` | Белый или чёрный фон по медианной яркости краёв изображения; значение по умолчанию |
| `white` | Белый фон |
| `black` | Чёрный фон |
| `transparent` | Прозрачные поля |

Скрипт ищет файлы `.jpg`, `.jpeg`, `.png` и `.webp`, включая вложенные папки. Структура папок сохраняется в папке результатов. К исходному имени файла добавляется `.webp`: например, `photos/trip/photo.jpg` превратится в `converted/trip/photo.jpg.webp`.

Папка результатов должна находиться вне исходной папки. Она и необходимые вложенные папки создаются автоматически. Если отдельный файл не удалось обработать, скрипт выводит ошибку и продолжает работу; в конце показывает число успешно обработанных фотографий.
